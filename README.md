# 龙潭祈愿

「龙潭祈愿」是一个为 DAO 龙潭数智乡建黑客松设计的 AI 民俗体验网页。它不做真实算命，也不做宗教服务，而是把屏南熙岭乡龙潭村的溪流、古厝、四平戏、红曲黄酒、文创市集、新村民生活转化为可交互的随机祈愿签和可分享海报。

它可以用于游客到村后的轻量互动，也可以作为文创集市、民宿、艺术空间、DAO 龙潭数字游民基地的传播入口。用户只需写下一个愿望，就能获得一支龙潭祈愿签、一段温柔签文、一个今日行动和一张带有龙潭在地意象的数字纪念海报。

## 技术栈

- Next.js
- TypeScript
- React
- Tailwind CSS
- App Router
- 本地随机生成逻辑
- SVG 海报生成
- `localStorage` 当前结果持久化

## 本地运行

```bash
npm install
npm run dev
```

默认访问 `http://localhost:3000`。

## 登录

项目当前保留两种进入方式：

- 乡建DAO数字游民身份账号密码登录
- 游客模式
